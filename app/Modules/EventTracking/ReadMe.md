# Event Tracking

### Avo CLI

The Avo CLI is used to generate the event tracking code. It is installed globally on the development machine. See
the [Avo CLI documentation](https://www.avo.app/docs/avo-cli) for more information on installing the avo cli.

Once installed and logged in run the following in the root of the project to regenerate the event tracking code:
```
    avo pull "Musora Web Platform"
```
