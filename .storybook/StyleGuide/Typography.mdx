# Tailwind CSS Typography Styles

This document provides an overview of the typography styles available in Tailwind CSS used in our project. Below are examples of various text styles along with their usage.

## Headings

<div style={{ fontSize: '2.25rem', fontWeight: '700' }}>Heading 1</div>
<div style={{ fontSize: '1.875rem', fontWeight: '700' }}>Heading 2</div>
<div style={{ fontSize: '1.5rem', fontWeight: '700' }}>Heading 3</div>
<div style={{ fontSize: '1.25rem', fontWeight: '700' }}>Heading 4</div>
<div style={{ fontSize: '1.125rem', fontWeight: '700' }}>Heading 5</div>
<div style={{ fontSize: '1rem', fontWeight: '700' }}>Heading 6</div>

```html
<h1 class="text-4xl font-bold">Heading 1</h1>
<h2 class="text-3xl font-bold">Heading 2</h3>
<h3 class="text-2xl font-bold">Heading 3</h3>
<h4 class="text-xl font-bold">Heading 4</h4>
<h5 class="text-lg font-bold">Heading 5</h5>
<h6 class="text-base font-bold">Heading 6</h6>
```

## Paragraphs

#### Regular Paragraph

<p style={{ fontSize: '1rem', lineHeight: '1.5' }}>This is a paragraph. Tailwind's default text size is 1rem with a line-height of 1.5.</p>
```html
<p class="text-base">
    This is a paragraph. Tailwind's default text size is 1rem with a line-height of 1.5.
</p>
```

#### Lead Paragraph

<p style={{ fontSize: '1.125rem', color: '#4A5568' }}>This is a lead paragraph. Tailwind's lead text size is 1.125rem with a slightly lighter color.</p>
```html
<p class="text-lg text-gray-700">
    This is a lead paragraph. Tailwind's lead text size is 1.125rem with a slightly lighter color.
</p>
```
