## Usage Guidelines

- **Primary Colors**: Use these colors for buttons, links, and key action items.
- **Secondary Colors**: Ideal for hover states, secondary actions, and less prominent elements.
- **Neutral Colors**: Best used for text, backgrounds, and to provide a neutral base.

### Example

```html
<div class="bg-primary-blue text-white p-4 rounded">
  This is a primary blue background with white text.
</div>

<div class="bg-secondary-gray text-secondary-yellow p-4 rounded">
  This is a secondary gray background with secondary yellow text.
</div>
