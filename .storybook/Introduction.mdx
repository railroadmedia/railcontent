# Welcome to Musora's Storybook

Here you'll find documentation and examples for all the components.

## How to Use Storybook

Storybook is a powerful tool for developing and documenting your UI components. You can browse through the various stories to see how components behave in different states.

## Getting Started

To get started, follow these steps:

1. Install dependencies: `npm install`
2. Run Storybook: `npm run storybook`
